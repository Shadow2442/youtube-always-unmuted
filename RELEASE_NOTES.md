# YouTube Always Unmuted v1.0.0

The first stable release automatically clears YouTube's player-level mute state while preserving the selected volume.

## Highlights

- Unmutes the active video in under one second.
- Handles YouTube's in-page navigation and replacement video elements.
- Uses no background process, telemetry, storage, or external network request.
- Works as an unpacked Manifest V3 extension in Brave and Chromium browsers.

## Installation

Download and extract `youtube-always-unmuted-v1.0.0.zip`, open `brave://extensions`, enable **Developer mode**, select **Load unpacked**, and choose the extracted folder.

The SHA-256 checksum is supplied alongside the ZIP in the GitHub Release.
