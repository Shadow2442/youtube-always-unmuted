How it works

One job, kept deliberately small.

01

Detect

The extension attaches to YouTube's active video element, including replacements created during in-page navigation.

02

Unmute

Media events trigger an immediate correction when the player becomes muted.

03

Preserve

Only the video element's mute flag changes. The selected volume remains exactly where you left it.

Installation

Load unpacked in Brave.

  1. 1Download and extract the latest release ZIP.
  2. 2Open brave://extensions.
  3. 3Enable Developer mode.
  4. 4Select Load unpacked.
  5. 5Choose the extracted folder containing manifest.json.
  6. 6Reload any YouTube tabs that were already open.
Quick test

Mute the YouTube player.

The player should restore audio in less than one second without changing its volume slider.

Your keyboard, Windows, or Brave tab mute controls still work normally.
